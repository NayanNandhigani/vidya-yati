How Vidya Yati's data fits together

This is the map for the backend build — every screen you've clicked through is a window onto these 41 tables. Each one below shows what it stores, in plain language, and which other tables it points to.

PK the field that uniquely identifies each row (a primary key) FK a field that points to a row in another table (a foreign key — how tables link up)
Simplified view — every table below ultimately traces back to a School. Full field-level links are listed under each table.
